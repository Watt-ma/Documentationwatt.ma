## Quand utiliser chaque intégration

- **API REST** : Idéale pour créer des tableaux de bord personnalisés, synchroniser les données avec votre ERP ou automatiser vos pipelines de reporting.
- **Webhooks** : À utiliser lorsque vous avez besoin de notifications push instantanées pour les alertes critiques, plutôt que d'interroger l'API.
- **Export CSV/Excel** : Idéal pour le rapprochement de facturation mensuel, les déclarations réglementaires ou l'analyse ponctuelle dans Excel.
- **SCADA/GTB** : Prévu pour les grands sites qui souhaitent superposer les analyses watt.ma à leurs systèmes de contrôle industriel existants.
