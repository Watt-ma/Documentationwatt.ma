L'API REST watt.ma vous permet de récupérer les relevés énergétiques, les métadonnées des compteurs et l'historique des alertes dans vos propres applications. Ce guide vous montre comment générer une clé API, authentifier vos requêtes et effectuer votre premier appel pour récupérer des données de compteur.

<Steps>
  <Step title="Générez une clé API">
    Rendez-vous dans **Paramètres** puis **Accès API** de votre compte watt.ma. Cliquez sur **Générer une nouvelle clé**, donnez-lui un nom descriptif (par exemple « Pipeline BI ») et copiez la clé immédiatement. Vous ne pourrez plus la consulter par la suite.
  </Step>
  <Step title="Authentifiez vos requêtes">
    Incluez la clé dans l'en-tête `Authorization` sous forme de jeton Bearer sur chaque requête :

    ```text
    Authorization: Bearer YOUR_API_KEY
    ```
  </Step>
  <Step title="Effectuez votre première requête">
    Utilisez curl ou tout client HTTP pour récupérer les derniers relevés. Remplacez `YOUR_API_KEY` par la clé que vous avez copiée :

    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
         https://api.wattsc.com/v1/readings
    ```

    Une réponse réussie renvoie un tableau JSON de relevés récents avec les horodatages, les identifiants de compteurs et les valeurs de consommation.
  </Step>
</Steps>

<Warning>
  Gardez votre clé API secrète. Ne la commitez pas dans un gestionnaire de sources et ne l'exposez pas dans du code côté client. Si une clé est compromise, révoquez-la immédiatement depuis **Paramètres \> Accès API** et générez-en une nouvelle.
</Warning>

## Limites de débit

Les limites de débit varient selon le plan :

| Plan | Requêtes par minute |
| --- | --- |
| Starter | 60 |
| Pro | 300 |

Si vous dépassez la limite, l'API renvoie `429 Too Many Requests`. Attendez une minute avant de réessayer, ou mettez en place un backoff exponentiel dans votre client.
