يتيح لك Wattsc REST API سحب قراءات الطاقة والبيانات الوصفية للعدادات وسجل التنبيهات إلى تطبيقاتك الخاصة. يوضح لك هذا الدليل كيفية إنشاء مفتاح API، والمصادقة على طلباتك، وإجراء أول مكالمة لك لاسترداد بيانات العداد.

<Steps>
  <Step title="أنشئ مفتاح API">
    انتقل إلى **Settings** ثم **API Access** في حساب Wattsc الخاص بك. انقر **Generate New Key**، وامنحه اسمًا وصفيًا (على سبيل المثال، "BI Pipeline")، وانسخ المفتاح على الفور. لن تتمكن من عرضه مرة أخرى.
  </Step>
  <Step title="مصادقة طلباتك">
    ضمّن المفتاح في رأس `Authorization` كـ Bearer token في كل طلب:

    ```text
    Authorization: Bearer YOUR_API_KEY
    ```
  </Step>
  <Step title="قم بأول طلب لك">
    استخدم curl أو أي عميل HTTP لجلب أحدث القراءات. استبدل `YOUR_API_KEY` بالمفتاح الذي نسخته:

    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
         https://api.wattsc.com/v1/readings
    ```

    تُرجع الاستجابة الناجحة مصفوفة JSON من القراءات الأخيرة مع الطوابع الزمنية ومعرّفات العدادات وقيم الاستهلاك.
  </Step>
</Steps>

<Warning>
  حافظ على سرية مفتاح API الخاص بك. لا تلتزم به في مستودع المصدر ولا تكشفه في التعليمات البرمجية من جانب العميل. إذا تم اختراق مفتاح، فقم بإلغائه فورًا من **Settings \> API Access** وأنشئ مفتاحًا جديدًا.
</Warning>

## حدود المعدل

تختلف حدود المعدل حسب الخطة:

| الخطة | الطلبات في الدقيقة |
| --- | --- |
| Starter | 60 |
| Pro | 300 |

إذا تجاوزت الحد، يُرجع API `429 Too Many Requests`. انتظر دقيقة واحدة قبل إعادة المحاولة، أو نفّذ backoff أُسيًا في عميلك.

## الخطوات التالية
