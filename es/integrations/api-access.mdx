La API REST de Wattsc le permite llevar lecturas de energía, metadatos de medidores y el historial de alertas a sus propias aplicaciones. Esta guía muestra cómo generar una clave de API, autenticar sus solicitudes y hacer su primera llamada para obtener datos de medidores.

<Steps>
  <Step title="Genere una clave de API">
    Vaya a **Configuración** y luego a **Acceso a la API** en su cuenta de Wattsc. Haga clic en **Generar nueva clave**, asígnele un nombre descriptivo (por ejemplo, "Pipeline de BI") y copie la clave de inmediato. No podrá verla nuevamente.
  </Step>
  <Step title="Autentique sus solicitudes">
    Incluya la clave en el encabezado `Authorization` como token Bearer en cada solicitud:

    ```text
    Authorization: Bearer YOUR_API_KEY
    ```
  </Step>
  <Step title="Realice su primera solicitud">
    Use curl o cualquier cliente HTTP para obtener las lecturas más recientes. Reemplace `YOUR_API_KEY` con la clave que copió:

    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
         https://api.wattsc.com/v1/readings
    ```

    Una respuesta exitosa devuelve un arreglo JSON de lecturas recientes con marcas de tiempo, IDs de medidores y valores de consumo.
  </Step>
</Steps>

<Warning>
  Mantenga en secreto su clave de API. No la incluya en el control de código fuente ni la exponga en código del lado del cliente. Si una clave se ve comprometida, revóquela de inmediato desde **Configuración \> Acceso a la API** y genere una nueva.
</Warning>

## Límites de tasa

Los límites de tasa varían según el plan:

| Plan | Solicitudes por minuto |
| --- | --- |
| Starter | 60 |
| Pro | 300 |

Si supera el límite, la API devuelve `429 Too Many Requests`. Espere un minuto antes de reintentar, o implemente un retroceso exponencial en su cliente.
