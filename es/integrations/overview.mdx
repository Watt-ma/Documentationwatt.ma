## Cuándo usar cada integración

- **API REST**: Ideal para construir tableros personalizados, sincronizar datos con su ERP o automatizar canalizaciones de reportes.
- **Webhooks**: Úselos cuando necesite notificaciones push instantáneas para alertas críticas, en lugar de consultar la API constantemente.
- **Exportación CSV/Excel**: Ideal para conciliación de facturación mensual, presentaciones regulatorias o análisis puntuales en Excel.
- **SCADA/BMS**: Planeado para grandes instalaciones que desean sumar las analíticas de Wattsc sobre sus sistemas de control industrial existentes.
