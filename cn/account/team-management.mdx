watt.ma 为团队而生。您可以邀请同事查看或管理电表、分配基于角色的权限，并在需要时撤销访问。本指南将说明如何添加成员以及每个角色可以做什么。

<Steps>
  <Step title="打开团队设置">
    点击右上角的头像，然后选择 **Team Management**。
  </Step>
  <Step title="邀请成员">
    点击 **Invite Member**，输入对方的邮箱地址，并从下拉菜单中选择角色。点击 **Send Invite**。收件人将收到一封邮件，其中包含加入您 watt.ma 组织的链接。
  </Step>
  <Step title="分配或更改角色">
    在团队列表中，点击任一成员旁边的角色标签以打开角色选择器。更改会立即生效。
  </Step>
  <Step title="移除成员">
    点击成员旁边的三点菜单，选择 **Remove**。其访问权限将立即被撤销，但其创建的报表或告警仍保留在账户中。
  </Step>
</Steps>

## 角色权限

| 权限 | Admin | Manager | Viewer |
| --- | --- | --- | --- |
| 查看仪表板和报表 | 是 | 是 | 是 |
| 创建和编辑告警 | 是 | 是 | 否 |
| 添加或移除电表 | 是 | 是 | 否 |
| 邀请和管理团队成员 | 是 | 否 | 否 |
| 管理账单和套餐 | 是 | 否 | 否 |
| 访问 API 密钥 | 是 | 否 | 否 |

## 最佳实践

- 仅将 **Admin** 授予负责账单和账户设置的人员。
- 将 **Manager** 用于需要配置电表和告警的设施经理或能源经理。
- 将 **Viewer** 用于只需要对报表进行只读访问的高管或财务人员。
