watt.ma REST API 允许您将能源读数、电表元数据和告警历史拉取到自己的应用中。本指南将向您展示如何生成 API 密钥、对请求进行身份验证，以及发起第一个调用来获取电表数据。

<Steps>
  <Step title="生成 API 密钥">
    在 watt.ma 账户中进入 **Settings**，然后进入 **API Access**。点击 **Generate New Key**，为其命名（例如 "BI Pipeline"），并立即复制该密钥。您将无法再次查看它。
  </Step>
  <Step title="对请求进行身份验证">
    在每个请求的 `Authorization` 头中以 Bearer 令牌形式包含该密钥：

    ```text
    Authorization: Bearer YOUR_API_KEY
    ```
  </Step>
  <Step title="发起第一个请求">
    使用 curl 或任意 HTTP 客户端获取最新读数。将 `YOUR_API_KEY` 替换为您复制的密钥：

    ```bash
    curl -H "Authorization: Bearer YOUR_API_KEY" \
         https://api.wattsc.com/v1/readings
    ```

    成功响应会返回一个 JSON 数组，包含最近的读数、时间戳、电表 ID 和消耗值。
  </Step>
</Steps>

<Warning>
  请妥善保管您的 API 密钥。切勿将其提交到源代码管理系统，也不要在客户端代码中暴露。如果密钥泄露，请立即在 **Settings \> API Access** 中撤销，并生成新密钥。
</Warning>

## 速率限制

速率限制因套餐而异：

| 套餐 | 每分钟请求数 |
| --- | --- |
| Starter | 60 |
| Pro | 300 |

如果超过限制，API 将返回 `429 Too Many Requests`。请等待一分钟后重试，或在客户端实现指数退避。
