L'analytique financière consolide en un seul tableau de bord les indicateurs qui pilotent l'activité d'un opérateur de recharge : revenu, encaissements, remboursements, marge, part propriétaire et règlements. Chaque métrique renvoie au rapport détaillé correspondant pour permettre l'analyse fine.

## Vue d'ensemble

Contrairement aux rapports individuels (revenus, encaissements, soldes), l'analytique financière propose une vision transverse sur une période donnée. Elle est conçue pour la direction financière, les investisseurs et les rapports mensuels de pilotage.

## Métriques disponibles

| Métrique | Description | Origine |
| --- | --- | --- |
| **Sessions** | Nombre de sessions terminées | [Suivi des sessions](/sessions/suivi-sessions) |
| **kWh délivrés** | Énergie totale sur la période | Compteurs OCPP 1.6J |
| **Revenu brut de recharge** | Valeur générée par les sessions | [Revenus](/rapports/revenus) |
| **Montant facturé** | Total des factures émises | [Facturation](/rapports/facturation) |
| **Montant encaissé** | Argent effectivement reçu | [Encaissements](/rapports/encaissements) |
| **Solde en attente** | Factures émises non payées | [Soldes clients](/rapports/soldes-clients) |
| **Solde en retard** | Factures échues et impayées | [Soldes clients](/rapports/soldes-clients) |
| **Remboursements** | Sommes retournées aux clients | [Remboursements](/rapports/remboursements-avoirs) |
| **Avoirs** | Crédits comptables émis | [Remboursements](/rapports/remboursements-avoirs) |
| **Coût électricité** | Coût d'acquisition de l'énergie | [Marge énergie](/rapports/marge-energie) |
| **Marge brute** | Revenu recharge moins coût électricité | [Marge énergie](/rapports/marge-energie) |
| **Frais de paiement** | Commissions CMI ou Stripe si disponibles | [Encaissements](/rapports/encaissements) |
| **Part propriétaire** | Cumul des parts partenaires | [Partage de revenus](/rapports/partage-revenus) |
| **Règlements à payer** | Montant dû aux partenaires | [Règlements](/rapports/reglements-partenaires) |
| **Règlements payés** | Montant déjà versé aux partenaires | [Règlements](/rapports/reglements-partenaires) |

## Filtres

Le tableau supporte les filtres suivants, combinables :

- Période (jour, semaine, mois, année, plage personnalisée)
- Organisation
- Compte de facturation
- Site
- Borne
- Moyen de paiement (QR CMI, virement, Stripe)
- Groupe de clients (voir [Tarifs par groupe](/sessions/tarifs-groupes))
- Statut de facturation

## Distinguer les notions financières

L'analytique financière expose côte à côte des chiffres qui ne se confondent pas :

- **Revenu facturé** ≠ **Revenu encaissé** ≠ **Revenu à régler** ≠ **Marge de l'opérateur**

<Note>
  Consultez la page [Revenus](/rapports/revenus) pour la définition précise de chaque notion. Les mélanger dans un rapport de direction est la principale source d'erreur d'interprétation financière.
</Note>
