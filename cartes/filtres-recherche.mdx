maps.watt.ma offre un système de filtrage puissant pour affiner votre recherche selon vos besoins spécifiques.

## Accéder aux filtres

Cliquez sur l'icône **Filtres** (entonnoir) situé en haut à gauche de la carte. Un panneau latéral s'ouvre avec tous les critères disponibles.

## Filtres par disponibilité

### Afficher uniquement les bornes libres
Active le filtre **Disponible maintenant** pour n'afficher que les stations avec au moins un connecteur libre.

### Filtrer par statut
- **Disponible** (vert) : au moins un connecteur libre
- **Occupée** (orange) : tous les connecteurs sont en utilisation
- **Hors service** (gris) : station en maintenance ou déconnectée
- **Inconnue** (jaune) : impossible de déterminer le statut en temps réel

Par défaut, seules les bornes disponibles et occupées sont affichées.

## Filtres par type de connecteur

Choisissez un ou plusieurs types de connecteurs compatibles avec votre véhicule :

- **Type 2** : standard européen pour véhicules électriques
- **CHAdeMO** : charge rapide DC (principalement véhicules asiatiques)
- **CCS Combo** : charge rapide DC (standard européen)
- **Schuko** : prise domestique 230V (charge lente)

Le filtre affiche uniquement les bornes proposant vos critères.

## Filtres par tarification

### Fourchette de prix
Utilisez le curseur pour définir la gamme de prix par kWh :
- **Gratuit** : certaines stations offrent gratuitement une recharge limitée
- **< 0,50 MAD/kWh** : tarif réduit
- **0,50 - 1,00 MAD/kWh** : tarif standard
- **> 1,00 MAD/kWh** : recharge rapide premium

### Type de tarification
Filtrez selon le modèle tarifaire :
- **Au kWh** : vous payez selon l'énergie consommée
- **Par minute** : tarification basée sur le temps de recharge
- **Forfaitaire** : prix fixe pour une session complète

## Filtres par services

Sélectionnez les services disponibles à proximité de la borne :

- **WiFi gratuit** : connexion internet
- **Parking** : stationnement sécurisé
- **Accessibilité PMR** : conforme aux normes handicap
- **Restaurant/Café** : commerces à proximité
- **Borne de gonflage** : service d'air comprimé
- **Douches** : installations sanitaires

## Filtres par opérateur

Affinez votre recherche selon le gestionnaire de la borne :

- **watt.ma** : réseau propre watt.ma
- **Partenaires publics** : collectivités, villes
- **Partenaires privés** : entreprises, hôtels
- **Réseaux tiers** : bornes d'autres fournisseurs

Vous pouvez combiner plusieurs opérateurs.

## Filtres par zone géographique

### Rayon de recherche
Sélectionnez le rayon de recherche autour de votre position :
- **1 km** : proximité immédiate
- **5 km** : quartier/zone
- **10 km** : ville
- **20 km** : région
- **50 km** : trajet court
- **100 km+** : long trajet

### Région
Filtrez par région administrative du Maroc :
- Grand Casablanca
- Fès-Meknès
- Marrakech-Safi
- Tanger-Tétouan-Al Hoceïma
- Autres régions

## Recherche par texte

Utilisez la **barre de recherche** pour trouver rapidement :

### Adresses
Tapez une rue, une ville, un code postal : `av. Hassan II, Casablanca`

### Points de repère
Recherchez par nom de bâtiment : `Université Al Akhawayn`, `Centre commercial Morocco Mall`

### Codes de station
Entrez l'identifiant unique d'une borne : `WAT-CAB-001`

### Opérateurs
Trouvez les bornes d'une entreprise : `watt.ma`, `AllEgo`, `E-Charge`

## Combinaison de filtres

Tous les filtres peuvent être combinés pour affiner au maximum votre recherche. Par exemple :

**Cas d'usage 1 : recharge rapide abordable**
- Type de connecteur : CCS Combo
- Tarif : < 0,80 MAD/kWh
- Rayon : 20 km
- Statut : Disponible

**Cas d'usage 2 : recharge tranquille avec services**
- Type de connecteur : Type 2
- Services : WiFi, Restaurant, Parking
- Rayon : 50 km
- Tarif : Par kWh (flexible)

**Cas d'usage 3 : recharge économique à proximité**
- Tarif : Gratuit ou < 0,50 MAD/kWh
- Rayon : 5 km
- Statut : Disponible

## Sauvegarde des filtres

Les filtres que vous appliquez sont **sauvegardés localement** dans votre navigateur. À votre prochaine visite, maps.watt.ma se souviendra de vos préférences.

Pour réinitialiser tous les filtres, cliquez sur **Réinitialiser les filtres** en bas du panneau latéral.

## Recherche par favoris

Si vous êtes connecté avec votre compte watt.ma, vous verrez vos **bornes favorites** filtrées automatiquement. Cliquez sur **Mes favoris** pour afficher uniquement vos bornes préférées.

<Tip>
  Utilisez la combinaison filtres + localisation GPS pour trouver la borne la plus adaptée à votre situation actuelle. Consultez les avis utilisateurs pour connaître la qualité du service avant de vous déplacer.
</Tip>

<Note>
  Certains filtres peuvent ne pas avoir de résultats selon votre zone de recherche. Élargissez le rayon ou modifiez vos critères pour afficher plus d'options.
</Note>
